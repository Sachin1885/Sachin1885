## About Me

I design and build full-stack applications with React, TypeScript, JavaScript, Node.js, Express, and Python. My public work includes a portfolio platform, inventory and billing systems, real-time communication apps, and AI-driven prototype tools.

My focus is backend-aware product engineering: clear workflows, dependable APIs, usable interfaces, and software that can be inspected, extended, and deployed with confidence.

## Currently Building

- Full-stack products using React, TypeScript, JavaScript, Node.js, and Express
- Backend workflows with authentication, PostgreSQL, SQLite, and persistent business data
- Real-time browser experiences using WebSocket and WebRTC concepts
- Python and ML prototypes for resume screening, matching, and experimentation
